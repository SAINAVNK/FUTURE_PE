# FUTURE_PE_01 — AI Website Copy Generator for a Local Business

## Project overview
This project demonstrates a reusable prompt workflow for writing clear, customer-focused website copy for a local business.

**Business selected:** Cafeteria Tirupati (a publicly listed cafeteria in Tirupati, Andhra Pradesh).

**Project status:** Independent portfolio concept created for learning purposes. This is not commissioned by, approved by, or published on behalf of the business.

## Objective
Create website-ready draft copy with:
- A homepage headline and value proposition
- A short introductory section
- Menu/service descriptions
- Clear calls to action (CTAs)
- A reusable prompt that can be adapted to other local businesses

## Files
- `prompts/website_copy_prompt.md` — reusable structured prompt and prompt logic
- `outputs/website_copy.md` — generated homepage, menu/services, and CTA copy
- `research_notes.md` — business information checked and items to verify before publication
- `social_post_draft.md` — draft LinkedIn post to customize and publish after uploading the repository

## Tools used
- ChatGPT — prompt design and draft content generation
- Markdown — documentation
- GitHub — public project repository and version control

## How to reproduce the workflow
1. Select a real business and review its publicly available business information.
2. Fill the prompt template with known details and intended audience.
3. Generate first-draft copy.
4. Review every factual claim, remove unsupported promises, and verify menu, contact, address, and opening-hour details.
5. Save the prompt and outputs in this repository.
6. Publish this repository publicly and share a LinkedIn post with the repository link.

## Important note
The copy is a proposal, not official business information. Verify all facts with the business before publication. Do not imply the business approved or used these drafts.
