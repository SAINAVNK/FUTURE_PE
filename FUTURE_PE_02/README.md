# FUTURE_PE_02 — AI Content Marketing Using UGC-Style Ads

## Project overview
This project demonstrates a reusable prompt system that generates short-form, creator-style promotional scripts for a local business. It includes multiple hooks, scripts, calls to action, captions, and platform adaptation notes.

**Business selected:** Cafeteria Tirupati, a publicly listed cafeteria in Tirupati, Andhra Pradesh.

**Project status:** Independent portfolio concept. This is not commissioned by, approved by, or published on behalf of the business. The scripts are mock ad concepts, not real customer testimonials.

## Objective
Build a repeatable prompt workflow for short-form ad concepts that:
- Starts with a specific audience need
- Uses multiple hooks
- Follows problem → solution → CTA
- Adapts to Instagram Reels, YouTube Shorts, and Facebook/Instagram placements
- Avoids invented testimonials, discounts, and factual claims

## Files
- `prompts/ugc_ad_prompt.md` — reusable prompt template
- `outputs/ugc_ad_pack.md` — hooks, scripts, CTAs, captions, and shot ideas
- `research_notes.md` — fact limits and review notes
- `social_post_drafts.md` — drafts for Instagram and LinkedIn sharing

## Tools used
- ChatGPT — prompt design and script drafting
- Markdown — project documentation
- GitHub — public repository and version control

## Reproduction steps
1. Choose a real business or product and identify its actual offer.
2. Add the audience, platform, desired length, tone, and CTA to the prompt.
3. Generate multiple creative options.
4. Remove any false claims, fake reviews, invented discounts, or promises.
5. Save prompt and output files in this repository.
6. Publish the repository publicly.
7. Create an Instagram post featuring the scripts or a mockup, briefly state the product and problem addressed, and tag `@future_interns`, as requested by the task instructions.

## Important note
Get permission before using a business's branding, photos, or identity in paid/promotional material. Do not present these scripts as actual customer experiences.
